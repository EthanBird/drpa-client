# DRPA Next 3.0.1 · Windows 与 UOS 模块化更新

本次更新扩展 Python Runtime Profile、数据工作台和浏览器运行环境，并修复 UOS 桌面中文输入与图标显示。

## 主要更新

- Python Runtime Profile 可导出为离线 `.drpac`，包含当前 Profile 已安装的用户包，并可改写名称与描述。
- Python 用户包支持多选和一键批量卸载，优先使用 uv，pip 作为降级方案。
- 数据工作台新增 MariaDB、CSV/TSV、JSON/JSONL/NDJSON 数据源，SQLite、Excel、CSV、JSON 文件可拖入直接创建连接。
- 丰富连接与数据表右键菜单，包括编辑/复制连接、创建表、增加字段、重命名、清空、删除和常用 SQL 模板。
- 浏览器环境可自动发现或手动选择 Chrome、Chromium、Edge、Brave、Vivaldi、Opera、Firefox；DrissionPage 自动化继续使用 Chromium 系浏览器。
- UOS 桌面不再强制禁用系统输入法，支持 DDE/Fcitx 中文组合输入，并保留 IBus/XIM 回退路径。
- UOS Core 同时安装 `drpa-next` 和 `drpa-desktop` 图标别名，并关联窗口类，改善 DDE 菜单与任务栏图标识别。

## 安装方式

- Windows：安装 `DRPA-Next-Core-Setup-3.0.1.exe`，再按需安装同页 `.drpac` 组件。
- UOS Desktop 20：安装 `drpa-next-core-3.0.1-1+uos20.modular1-linux-x86_64.deb`，再通过图形向导或 `drpa component install` 安装 UOS `.drpac` 组件。
- 现有 3.0.0 用户可保留浏览器、WebView2、JCode 与 Python Runtime；更新 Core 和 `org.drpa.desktop-ui.drpac` 即可获得本次桌面功能。UOS 用户应使用本发布中的 UOS 专用组件。

所有安装包均为本地构建，未使用 CI 构建产物。发布资产附带 SHA-256 校验文件或校验清单。
