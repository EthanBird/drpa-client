# DRPA Next 3.0.0 · Windows x64 模块化离线版

DRPA 3.0 将 Windows 发行拆分为轻量 Core Setup 与可插拔 `.drpac` 组件。基础安装不依赖 WebView2、Chrome、Node.js 或系统 Python；即使桌面渲染组件尚未安装，也可以通过 `drpa.exe` 和原生 egui 向导管理环境、安装组件与运行 RPAZ。

## 下载与安装

1. 下载 `drpa-next-3.0.0-windows-x86_64-setup.exe`。
2. 按需下载同一 Release 中的 `.drpac`，放在 Setup 同目录或任意本地目录。
3. 安装完成后使用组件向导扫描或选择组件包。已有系统 WebView2、Chrome、Chromium、Edge 或 Brave 时，向导会优先复用系统能力。
4. 推荐首次安装 `org.drpa.desktop-ui.drpac` 与一个 Python runtime；浏览器、固定 WebView2、JCode 可按需安装。

## 主要更新

- 轻量、无注册表 Setup；支持安装目录发现、覆盖更新、修复与卸载组件。
- `.drpac` 事务安装、SHA-256 校验、激活、回滚、热切换与垃圾回收。
- Python Runtime Profile 与 uv/pip 包管理，提供 Python 3.14 Minimal 可选运行时。
- 数据工作台修复 SQLite 快捷键上下文，增加服务端分页、可调页长、表右键操作，以及 CSV、JSON、SQL、XLS、XLSX 导出。
- AI Agent/JCode 增强重复工具调用保护、轨迹保留、项目上下文和浏览器能力发现。
- 桌面入口支持普通用户、开发者和自定义模式。

## 文件校验

Release 同时提供 `SHA256SUMS.txt` 与 `components/catalog.json`。组件向导安装前仍会再次校验包内清单、文件长度与 SHA-256。

Windows 文件为本地构建；本次发布未使用 CI 构建产物。Linux/UOS 继续使用已有平台包，不包含在此 Windows Release 中。
