# DRPA 数据工作台

数据工作台采用“连接与元数据、查询执行、结果集、数据操作”四层结构。交互能力参考 DBX，但保留 DRPA 现有 React + Tauri + Rust 技术栈；DBX 是 Vue 应用，因此不直接嵌入其页面或运行时。

## 当前能力

- 工作区 SQLite、外部 SQLite、Excel、PostgreSQL、MySQL 数据源。
- Monaco SQL 编辑器，`Ctrl/Cmd + Enter` 执行选中 SQL 或全文 SQL。
- 服务端分页，页大小可选 100、500、1,500、5,000、10,000、20,000；远程查询按流读取，不预先加载完整结果集。
- 当前页筛选和列排序；双击单元格复制完整显示值。
- 导出当前页或全部查询结果，支持 XLSX、Excel 2003 XML（`.xls`）、CSV、JSON、SQL INSERT。
- 表和视图搜索；表右键支持浏览数据、统计行数、查看字段、生成 SELECT/INSERT/UPDATE、查看 SQLite 建表 SQL、复制表名和刷新结构。
- 查询历史、数据库结构检查和 AI SQL 生成。

## 生产化路线

后续能力按模块继续扩展，避免重新堆成单个巨型页面：

1. 查询会话：多查询页签持久化、事务模式、查询取消、执行计划和慢查询诊断。
2. 大结果集：虚拟滚动、服务端排序/筛选、可恢复的流式全量导出。
3. 数据编辑：主键感知的行编辑、变更预览、批量提交与回滚。
4. Schema 工具：表/字段/索引/外键/触发器编辑、DDL 预览、Schema diff 和 ER 图。
5. 数据工程：CSV/Excel 导入映射、跨库传输、备份恢复、数据与结构对比。

任何破坏性 Schema 或数据操作都必须先显示 SQL 预览和影响范围，并由用户明确确认。
