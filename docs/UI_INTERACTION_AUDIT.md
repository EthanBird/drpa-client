# UI 交互审查

本表用于区分“已经接通”“明确禁用”和“仍在规划”的界面，避免显示一个看似可点击但没有行为的控件。

## 已接通

- 无边框标题栏：空白区拖动，双击最大化/还原，最小化、最大化/还原、关闭。
- 导航与命令面板：总览、脚本包、工作台、运行记录、开发工作室、设置。
- 脚本包：文件选择安装、搜索、网格/列表视图、进入运行工作台。
- 工作台：选择包/任务、编辑参数、文件与目录选择、重置、保存、预检、真实运行。
- 开发工作室：按名称创建、编辑/保存、直接运行、导出 RPAZ、打开已安装包、Notebook 执行。
- 设置：紧凑模式持久化、实际数据目录展示与复制、交互能力状态。

## 明确禁用

- 多工作区切换：标题栏控件带禁用状态和说明，当前版本只有一个离线工作区。
- 运行详情：运行记录行末控件保持禁用，直到 Host 提供逐次运行详情和日志查询 API。
- 自动化、运行环境、凭据：页面明确标记“开发中”，唯一动作使用原生 `disabled`，不会伪装成已实现。

新增交互时必须满足以下之一：绑定可验证的 handler、使用原生 `disabled` 并说明原因，或从 UI 中移除。禁止保留无 handler 的可用态按钮。
