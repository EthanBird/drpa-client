# 营销销户派工自动化

这是一个根据现有 DrissionPage 脚本整理出来的 DRPA 示例脚本包。

## 功能范围

脚本会尝试在营销管理系统中执行：

1. 打开营销管理系统。
2. 进入岗位待办并查询销户工单。
3. 签收工单。
4. 执行现场停电。
5. 进入个人待办工单。
6. 选择人员传递。
7. 计量装置装拆任务分派。
8. 发送作业信息并制定计划。

## 注意事项

- 该脚本面向内网业务系统，外部环境无法直接运行。
- 原脚本中改派工单相关函数未实现，本包保留为 TODO，主流程不会调用。
- 推荐先在测试环境运行，确认页面元素、人员姓名、计划类型和班组名称仍然有效。
- 默认不使用无头浏览器。

## 参数

参数表由 `manifest.yaml` 中的 `params` 自动生成。主要参数包括：

- 系统 URL
- 业务类型关键字
- 循环处理次数
- 计划日期偏移天数
- 负责人 / 协助人 / 操作人
- 负责人电话
- 工作地点前缀
- 计划内容前缀
- 计划内容删除文本
- 勘查方式
- 专业分类
- 安监作业类型
- 计划开始/结束时间

## 打包

```bash
python3 tools/build_example_packages.py
```
