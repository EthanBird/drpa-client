DRPA 开发概览

DRPA Next 将 RPAZ 包管理、开发工作室、任务运行、Jupyter 实验、AI Agent 与离线运行环境放在同一桌面 Host 中。目标机器不依赖系统 Python、Node.js 或在线安装。

核心边界

UI

React / TypeScript

页面只通过 typed Tauri invoke 访问本机能力。

HOST

Rust Host

负责包校验、项目文件、任务、更新协议与 Agent 工具策略。

RUNTIME

Sealed Python

固定 CPython、离线 wheels、Chrome 与 Jupyter 由全量安装包提供。

PACKAGE

RPAZ schema 2

ZIP 根目录包含 manifest.yaml，入口使用 main(ctx)。

仓库结构

apps/desktop/          Tauri + React 桌面端
crates/drpa-host/      Host 状态与任务生命周期
crates/drpa-package/   RPAZ schema、归档与路径校验
crates/drpa-protocol/  Rust/TypeScript DTO
runtime/python/        Python adapter、Kernel bridge
examples/              可运行示例包
installer/windows/     无注册表 NSIS 安装器
tools/windows/         安装库存与差量包构建

最短开发闭环

  1. 在“开发工作室”新建项目，编辑 manifest.yaml 与 main.py。
  2. 使用 Notebook 验证逻辑，再整理到入口函数。
  3. 直接运行工作副本，检查结构化日志、进度和产物。
  4. 构建 RPAZ，安装到“脚本包”，创建任务配置并执行。
