RPAZ 开发规范

RPAZ 是可移植 ZIP 包。Host 在安装和构建时检查 schema、ID、入口、安全路径、重复参数、文件数量与解压预算。

最小 manifest

schema: 2
id: com.example.daily-image
name: 每日图片
version: 0.1.0
entrypoint:
  runtime: python
  module: main.py
  callable: main
runtime:
  python: "3.11.*"
parameters:
  - id: count
    type: number
    required: false
    default: 1

入口与 Context

def main(ctx):
    count = int(ctx.parameters.get("count", 1))
    ctx.log.info(f"准备处理 {count} 项")
    output = ctx.outputs / "result.json"
    output.write_text('{"ok": true}', encoding="utf-8")
    ctx.artifact(output, "application/json")
    ctx.progress(100, "处理完成")
API用途
ctx.parameters当前任务配置解析后的参数。
ctx.outputs本次运行独立产物目录。
ctx.log结构化日志。
ctx.progress()报告进度与阶段。
ctx.artifact()登记可查看产物。
入口和资源必须使用包内相对路径；绝对路径、父目录跳转、符号链接和大小写冲突会被拒绝。
