资产规则

发布类型资产用途

更新事务

  1. Host 检查 schema、Host/Worker protocol、最低 Host 版本、平台和精确 baseVersion。
  2. 校验安全路径、文件数量、压缩率和实际写入大小，不执行逐文件哈希计算。
  3. 包内 Worker 写入 worker-ready，Host 才退出。
  4. Worker 备份并替换受管文件，从安装目录启动新 Host。
  5. 新 Host 写入 startup-ack 后才清理备份，否则自动回滚。
data/ 与 Fixed Version WebView2 始终受保护。Chrome/runtime 只有库存指纹变化时才进入日常包。
