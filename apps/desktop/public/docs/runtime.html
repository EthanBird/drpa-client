离线运行环境

全量安装布局提供 CPython 3.11、离线依赖闭包、Chrome for Testing、Jupyter Kernel 与 Fixed Version WebView2。日常更新复用这些大文件。

安装布局

<install>/
├── DRPA Next.exe
├── drpa-updater.exe
├── install-manifest.json
├── runtime/
│   ├── manifest.json
│   ├── python/
│   ├── wheels/
│   └── browser/
├── webview2/
└── data/

初始化流程

  1. Host 读取 runtime/manifest.json，选择精确解释器和浏览器。
  2. 在最终路径的 data/runtime-environment 创建隔离环境。
  3. 只从随包 wheels 安装固定依赖，不访问在线 pip。
  4. 导入 drpa_runner、DrissionPage 与 Jupyter 依赖完成健康检查。
裸 EXE 或仅含 Host 的 GUI 测试目录不代表全量安装布局。出现“未找到封装 Python 运行时”时，先确认同目录存在完整 runtime/manifest.json；正式 Setup 会一起释放该目录。
