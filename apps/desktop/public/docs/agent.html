OpenAI-compatible + local tools

AI Agent 开发助手

Agent 使用 OpenAI-compatible Chat Completions，并只通过 RPAZ 专用工具访问本地项目。URL、模型和默认项目会保存；API Key 仅保留在当前应用进程。

会话模型

独立上下文

每个会话保存标题、绑定项目、消息、工具事件与更新时间；切换会话不会混合历史。

本机持久化

会话支持新建、切换、重命名、清空和删除。

内置工具

工具能力
rpaz_list_files列出绑定项目文件。
rpaz_read_file读取项目文本。
rpaz_write_file写入受路径策略约束的文件。
rpaz_validate校验 manifest 和入口。
rpaz_build构建 RPAZ。
rpaz_python调用 sealed Python 辅助处理。

使用步骤

  1. 展开“Agent 配置”，填写兼容 URL 和模型。
  2. 选择开发项目，确认六个工具显示 ACTIVE。
  3. 新建会话并描述任务；Agent 最多执行 8 轮工具调用。
  4. 检查工具输出和文件变更，再运行与构建。
