# 知识文档

## 页面用途

“知识文档”是当前工作区的离线 Markdown 文档管理器，提供文件树、根目录/子目录创建、编辑、预览、内部链接、导入和导出。本文所在的 `DRPA使用文档` 也由此页面展示。

## 适用场景

- 编写项目规范、操作手册和故障记录。
- 建立目录化团队知识。
- 导入现有 Markdown 并继续编辑。
- 用相对链接连接多篇本地文档。
- 给 AI Agent 提供精确原文，而不是语义向量检索。

## 前置条件

- 当前工作区知识目录可写。
- 导入文件必须是 UTF-8 编码 `.md` 或 `.markdown`。
- 单篇文档不能超过页面/Host 规定的大小上限。

## 界面区域

1. **页面标题与说明**：显示本地离线知识文档定位。
2. **左侧搜索与文件树**：按名称过滤、刷新、展开目录和右键菜单。
3. **中央编辑区**：欢迎页或当前文档。
4. **模式切换**：阅读、编辑、分栏。
5. **保存按钮**：仅有未保存修改时可用，支持 `Ctrl+S`。
6. **状态栏**：提示、UTF-8、Markdown 和字符数。

## 创建根目录和文档

1. 在左侧文件树空白区域右键。
2. 选择“新建根目录”或“新建根文档”。
3. 输入名称并按 Enter；文档必须以 `.md` 或 `.markdown` 结尾。
4. 在目录上右键可新建子目录/子文档。
5. `Esc` 取消正在输入的名称。

最外层创建必须在空白区域右键；对已有条目右键显示的是该条目的操作。

## 编辑、链接和保存

1. 单击文档打开。
2. 选择“编辑”或“分栏”。
3. 修改 Markdown。
4. 用相对路径链接同目录文件，例如 `[运行环境](12_运行环境.md)`。
5. 点击保存或按 `Ctrl+S`。
6. 切换文档前观察是否仍显示未保存状态。

预览中的相对 `.md` 链接会在当前知识文档树打开；`http://`/`https://` 链接由外部浏览器处理。

## 导入、拖入和导出

- 导入可一次选择多个 Markdown，目标为当前目录。
- 把 Markdown 拖入页面也会导入；同名文件会生成不覆盖的名称。
- 选中文档后导出，系统保存窗口要求 `.md` 或 `.markdown`。
- 导入前确保 UTF-8；其他编码会被拒绝以避免乱码。

## 条目与状态解释

- **directory**：目录，可包含子目录与文档。
- **file**：可编辑 Markdown。
- **dirty/未保存**：内存内容和磁盘不同。
- **preview/edit/split**：阅读、编辑、分栏模式。
- **本地离线**：文件属于工作区，不依赖网络。
- **默认文档**：安装或升级时只在目标不存在时补齐，不覆盖用户修改。

## 与知识库和 Agent 协作

- [知识库](10_知识库.md)用于多源、分块和向量检索；知识文档不自动向量化。
- [AI Agent](09_AI_Agent.md)可按权限列出、读取或写入知识文档。
- [设置](14_设置.md)中的“知识与记忆写入”控制 Agent 是否能修改。
- 重要运行规范可从[运行工作台](05_运行工作台.md)或[开发工作室](03_开发工作室.md)手工链接。

## 限制与安全

- Host 拒绝 `..` 路径穿越、保留名和符号链接跟随。
- 只列出 Markdown，其他文件不会作为知识文档显示。
- 删除目录会递归删除其中全部文档；确认框会显示目标路径。
- 业务秘密、密码和 API Key 不应写入文档，因为内容可进入 Agent 上下文和工作区导出。
- 默认文档升级不覆盖同名用户文件；旧版默认手册迁移时，用户改过的内容会以“旧版用户修改”文件保留。

## 常见问题与排错

- **最外层右键没有菜单**：在文件树条目之外的空白处右键，不要在编辑区或现有条目上。
- **新文档创建失败**：确认扩展名、父目录存在、名称无路径穿越或保留前缀。
- **保存按钮是灰色**：内容没有变化、正在忙或未打开文件。
- **导入后出现 `(1)`**：同名目标已存在，系统为避免覆盖自动改名。
- **Markdown 链接提示不存在**：路径相对当前文档解析；检查文件名、目录和大小写。
- **只看到标题没有内容**：切换阅读/编辑/分栏，刷新文件树并确认文件是 UTF-8。
- **删除后能恢复吗**：页面删除是本地文件删除，不保证回收站；重要目录先导出或备份。
- **为什么手册是单层文件**：便于一次展开查看全部页面，不需要逐层打开目录。
