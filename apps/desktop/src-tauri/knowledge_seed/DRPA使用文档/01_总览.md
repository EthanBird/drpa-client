# BI 总览

## 1. 功能定位

“总览”现在是当前工作区的低代码 BI 主页。你可以把 DRPA 运行数据、RPAZ 包信息、工作区 SQLite 或数据工作台中的数据库查询放在同一张自适应画布上。

每个工作区拥有独立的仪表盘配置。切换工作区时，主页布局和数据源引用也会随工作区切换。

## 2. 默认主页

首次打开时会创建“业务总览”，默认包含：

- 活动任务；
- 30 天成功率；
- 已安装 RPAZ 包数量；
- 预计节省时间；
- 最近运行耗时；
- 运行状态分布；
- 最近运行数据表。

这些组件使用 DRPA 内置数据，不要求先创建数据库表。

## 3. 编辑主页

点击右上角“编辑主页”进入设计状态。顶部组件栏可以添加：

| 组件 | 适用内容 |
| --- | --- |
| 指标 | 总金额、成功率、任务数等单值 |
| 折线图 | 时间趋势、连续指标 |
| 柱状图 | 分类对比、排名 |
| 饼图 | 少量分类的占比 |
| 数据表 | 明细、查询结果 |
| Markdown | 标题、结论、数据口径和操作说明 |

拖动组件标题可以调整位置；拖动组件右下角可以调整大小。完成编辑后点击“完成编辑”。修改会自动保存，工具栏会显示“保存中”“已保存”或“保存失败”。

## 4. 栅格与自适应

仪表盘默认使用 12 列栅格。属性面板可以选择 8、12、16 或 24 列，并调整基础行高。

窗口变窄时，DRPA 会把基础布局投影为 8 列或 4 列显示。响应式投影不会破坏宽屏布局，因此重新放大窗口后仍会恢复原来的组件位置和比例。

## 5. 使用 DRPA 内置数据

组件的数据来源选择“DRPA 内置数据”后，可以选择：

- **工作区指标**：活动任务、成功率、包数量、节省时间、运行总数；
- **运行记录**：包名、任务配置、状态、开始时间、耗时和进度；
- **运行状态汇总**：按成功、失败、运行中等状态统计数量；
- **RPAZ 包**：名称、版本、运行时、可信级别和任务配置数量。

在“字段映射”中，把分类字段和数值字段映射到图形通道。例如柱状图可使用 `status` 作为分类字段、`count` 作为数值字段。

## 6. 使用数据工作台

组件的数据来源选择“数据工作台”后：

1. 选择“内置工作区 SQLite”或数据工作台中已有的连接；
2. 输入只读 SQL；
3. 等待查询完成；
4. 在字段映射中选择查询结果字段；
5. 选择数值格式、主色和刷新周期。

示例：

```sql
SELECT
  strftime('%Y-%m', created_at) AS month,
  SUM(amount) AS total_amount
FROM orders
GROUP BY strftime('%Y-%m', created_at)
ORDER BY month
```

BI 查询只接受只读语句。工作区 SQLite、外部 SQLite、Excel、PostgreSQL 和 MySQL 都复用数据工作台的连接配置与查询限制。

PostgreSQL 和 MySQL 密码需要在当前会话输入，密码不会写入仪表盘文件。SQLite 和 Excel 文件连接不需要密码。

## 7. 多仪表盘

点击仪表盘选择器旁的加号可以创建空白仪表盘。选择器用于切换主页。属性面板可以修改名称、描述、列数和行高。

删除仪表盘需要连续点击两次删除按钮。最后一个仪表盘会保留，避免工作区失去主页。

## 8. 刷新

- “刷新数据”会立即重新执行当前仪表盘的数据加载；
- 单个组件可以设置手动、10 秒、30 秒、1 分钟或 5 分钟自动刷新；
- 数据表最多显示前 50 行，但底层查询仍遵循数据工作台的统一限制；
- 组件标题栏显示返回行数和查询耗时。

## 9. 配置位置与备份

当前工作区的定义保存在：

```text
dashboard/home.json
```

该文件只保存布局、SQL 和显示选项，不保存查询结果与数据库密码。它会随工作区数据一起导出和备份。
