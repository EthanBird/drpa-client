# 数据工作台

## 页面用途

“数据工作台”用于创建工作区数据源、浏览表结构、编写并执行 SQL。支持 PostgreSQL、MySQL、SQLite 和 Excel 类文件，并为 AI Agent 的只读数据工具提供连接元数据。

## 适用场景

- 临时查看 SQLite 数据库或 Excel 工作簿。
- 保存 PostgreSQL/MySQL 连接配置并反复查询。
- 查看表、视图、字段、主键、默认值和空值约束。
- 让 AI SQL 助手根据当前结构生成查询草稿。

## 前置条件

- 远程数据库必须能从本机访问，且账号具有所需只读权限。
- SQLite/Excel 文件必须存在且可读。
- PostgreSQL/MySQL 密码不会持久化，重启应用后需要重新输入。
- AI SQL 助手还需要在[设置](14_设置.md)配置可用模型连接。

## 界面区域

1. **左侧连接区**：新建、选择和编辑连接；显示连接状态。
2. **对象树**：列出表和视图；单击看字段，双击生成查询。
3. **数据库路径/端点**：文件源显示路径，远程源显示端点。
4. **中央 SQL 编辑器**：新建、编辑和执行查询。
5. **结果表格**：显示列、行号和单元格值。
6. **字段面板**：显示数据类型、主键、NOT NULL 和默认值。
7. **AI SQL 助手**：根据结构与自然语言生成 SQL，但不自动执行。

## 创建连接

### SQLite 或 Excel

1. 点击“连接”标题旁 `+`。
2. 选择 SQLite 或 Excel，填写连接名称。
3. 点击“浏览”选择文件；也可把文件直接拖入数据工作台。
4. 保存后选择连接，等待对象树加载。
5. Excel 每个工作表按可查询对象呈现，只读访问原内容。

支持的典型扩展名：SQLite 为 `.db`、`.sqlite`、`.sqlite3`；Excel 类为 `.xls`、`.xlsx`、`.xlsb`、`.ods`。

### PostgreSQL 或 MySQL

1. 新建连接并选择数据库类型。
2. 填写名称、主机、端口、数据库和用户名。
3. 输入密码；该值只存在本次应用内存。
4. 保存并选择连接，确认状态变为本次会话已连接。

## 查询流程

1. 选择连接。
2. 单击表查看字段；双击表生成基础查询，或点击“新建查询”清空编辑器。
3. 审阅 SQL，确认只针对预期对象。
4. 执行后检查结果列、行数和错误提示。
5. 需要辅助时打开 AI SQL 助手，描述指标、分组、筛选和排序。
6. 把生成 SQL 当作草稿审阅，再手动执行。

## 字段与状态解释

- **连接正常**：文件可打开或远程会话已建立。
- **需要输入密码**：配置存在，但本次应用尚未获得远程密码。
- **主键**：字段卡片钥匙标记。
- **NOT NULL**：列不允许空值。
- **默认值**：来自数据库元数据，不代表所有历史行都有该值。
- **SQLite/Excel**：文件路径保存在工作区；Excel 查询只读。

## 与其他页面协作

- [AI Agent](09_AI_Agent.md)可列连接、读结构和执行只读 SQL。
- [知识库](10_知识库.md)适合把 Excel/文档内容建立语义索引，但不是 SQL 替代品。
- 在[设置](14_设置.md)分别控制数据库只读和创建连接工具。
- 分析脚本可在[开发工作室](03_开发工作室.md)或 Agent 项目中复用数据。

## 限制与安全

- Agent 不提供 `INSERT`、`UPDATE`、`DELETE`、DDL 或事务写工具。
- 人工 SQL 编辑器是否允许写入取决于宿主实现与账号权限；生产库应使用只读账号。
- 不保存远程密码；不要把密码写进连接名称、SQL、Agent 对话或知识文档。
- Excel 数据类型由文件内容推断，混合类型列可能需要显式转换。
- 拖入文件会创建工作区数据源，先确认文件可复制和留存。

## 常见问题与排错

- **远程连接一直要求密码**：这是重启后的正常状态；重新编辑连接输入密码。
- **Excel 工作表不见了**：检查文件格式、隐藏表和是否被其他程序独占；刷新连接。
- **SQLite 报文件不可读**：确认不是损坏文件、快捷方式或无权限路径。
- **AI 生成的 SQL 方言不对**：明确说明连接类型，并检查助手是否读取了当前结构。
- **结果为空**：先执行简单 `SELECT` 验证表，再检查日期范围、NULL 和连接的数据库名称。
- **Agent 拒绝写数据**：这是设计边界；需要写入时应由人工使用受控迁移或专用业务工具。
