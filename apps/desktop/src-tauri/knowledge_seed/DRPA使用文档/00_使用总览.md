# DRPA 使用总览

DRPA（Data · Runtime · Process · AI）是一套本地优先的自动化工作区：用项目组织开发素材，用 RPAZ 规范封装可运行任务，用数据与知识能力提供上下文，再通过流程或 AI Agent 协同完成工作。

## 1. 这套手册怎么用

本目录与桌面端左侧导航一一对应，共 15 篇页面手册。每篇都包含适用场景、前置条件、界面区域、操作流程、字段与状态、跨页面协作、安全边界和排错。文档是当前工作区中的可编辑 Markdown；更新只补充不存在的默认文件，不覆盖你的修改。

## 2. 第一次使用的推荐顺序

1. 在[设置](14_设置.md)确认当前工作区、界面和 AI Agent 连接。
2. 在[运行环境](12_运行环境.md)确认 Python、Jupyter 与浏览器依赖可用。
3. 在[开发工作室](03_开发工作室.md)创建项目，逐步运行 Notebook 或源码。
4. 需要标准化交付时，将项目整理为 RPAZ 并直接保存到[RPAZ 包](02_RPAZ包.md)。
5. 在[运行工作台](05_运行工作台.md)预检参数并运行，到[运行记录](06_运行记录.md)复核。
6. 重复任务再交给[自动化计划](07_自动化计划.md)；需要多步 AI 编排则使用[流程设计](08_流程设计.md)。

## 3. 核心概念

### 工作区

工作区是最外层隔离边界。项目、RPAZ 包、任务配置、运行历史、Agent 会话、知识文档、向量知识库、插件配置和产物均属于当前工作区。顶部工作区菜单可创建或切换工作区；桌面端切换后会重新加载，避免跨区写入。

### 通用项目与 RPAZ

通用项目是可供 Agent、Python 和开发工作室使用的普通工作目录。具有 `manifest.yaml`、固定入口和参数/产物约定的项目是 RPAZ 规范化子集，可以校验、构建、安装、运行和调度。

### 知识文档与知识库

知识文档保存可编辑 Markdown 原文，不自动向量化；知识库导入 PDF、Office、网页、文本等来源并建立检索索引。精确规范放知识文档，大量异构资料放知识库。

## 4. 通用界面

- 左侧主导航收窄后保留图标栏，图标仍可切换页面。
- 各工作台的左右侧栏可以独立收起，收起后使用边缘恢复按钮。
- `Ctrl+K` 打开命令面板，`Esc` 关闭浮层。
- “设置 → 外观”可切换主题、字号、密度和页面大标题。
- 页面右下或顶部的提示条会报告保存、导入、运行及错误结果；不要在提示出现前重复点击。

## 5. 数据与安全原则

- 数据库 Agent 工具只读，不提供写数据或 DDL 工具。
- 任意文件能力默认只读；写入仅限绑定项目或隔离产物目录。
- API Key、数据库密码和令牌不得写入项目、知识文档、日志、流程 DSL 或聊天内容。
- 导出工作区会包含业务项目、会话和文档，应按敏感文件保管。
- 删除项目、目录、会话、知识库或插件前，先检查影响范围；删除提示中的对象名称就是实际目标。

## 6. 常见问题

**切换工作区后内容“不见了”？**
这是隔离生效。打开顶部工作区菜单切回原工作区，而不是重新导入一份数据。

**页面太拥挤？**
先收起页面内部侧栏；主导航只收窄为图标栏。还可在设置切换“紧凑”或隐藏页面大标题。

**操作没有结果？**
先看页面提示，再到运行记录或运行环境检查。涉及模型时，还要确认兼容 URL、模型名和服务端是否正在监听。

**这些说明会进入向量检索吗？**
不会。它们属于知识文档。若确有语义检索需求，可将选定资料另行导入知识库。
