# AI Agent

## 页面用途

“AI Agent”提供持久、多会话的本地智能工作台，支持普通问答、项目开发、Python、只读数据分析、知识检索、Skills、插件工具，以及 PDF、Word、Excel、PowerPoint 的读取、创建与转换。

## 适用场景

- 在普通会话中问答、总结或处理附件。
- 按项目组织长期开发与分析会话。
- 让 Agent 读取/修改项目文件并运行 Python。
- 查询数据工作台或向量知识库。
- 显式选择“数据分析”等 Skills。
- 在开发工作室右侧使用同一会话能力协作当前项目。

## 前置条件

1. 在[设置](14_设置.md)配置 OpenAI 兼容 URL、模型和需要的工具权限。
2. 模型服务正在监听且支持 Chat Completions/工具调用。
3. Python 必须在会话绑定项目后才能运行。
4. 数据库、知识库、插件工具应先在各自页面准备。

## 界面区域

1. **顶部标题与操作**：连接状态、显示/隐藏配置、清空当前对话。
2. **左侧会话栏**：
   - 新建普通会话；
   - 项目树及项目内会话；
   - 最近会话；
   - 会话重命名和删除。
3. **中央对话区**：消息、Markdown、工具事件、流式状态和重新生成。
4. **输入区**：文字、附件、Agent 产物、Skills、项目状态与发送。
5. **右侧配置**：模型连接、生成参数、项目上下文和内置工具状态。

所有会话正文保存在当前工作区 `agent/session.db`，无固定数量上限；列表先加载摘要，打开时再读取正文。

## 会话和项目操作

### 普通会话

1. 点击“新建普通会话”。
2. 输入问题，`Ctrl+Enter` 发送。
3. 第一条消息会形成会话标题；也可在左侧手工重命名。
4. 普通会话可问答和处理文档，但未绑定项目时不能运行项目 Python。

### 创建项目并组织会话

1. 点击“项目”标题旁 `+`，或在会话栏空白处右键“新建项目”。
2. 输入项目名称。这里创建的是通用项目目录。
3. 点击项目右侧 `+` 创建绑定会话；也可把普通会话通过右侧“工作上下文”移动到项目。
4. 展开项目查看多个会话；右键项目可新建会话或重命名。
5. 带 `manifest.yaml` 和 RPAZ 规范的项目会标为“RPAZ 子集”，额外获得校验/构建工具。

### 会话维护

- 重命名只改变标题。
- 清空对话删除消息但保留会话。
- 删除会话会从本机会话数据库移除全部消息。
- 最近会话按更新时间排列；项目会话在项目树和最近区域可能同时出现快捷入口。

## 发送消息、重新生成和工具复核

1. 写清目标、输入、期望输出和允许修改范围。
2. 发送后，流式模式会逐步显示 Markdown。
3. 工具调用以可展开事件显示；检查工具名、状态、摘要和输出。
4. 最后一条用户消息可编辑并从该处重新生成，后续分支会被替换。
5. 最后一条回复也可重新生成。
6. 工具失败时不要盲目重试，先读错误并修正权限、项目或输入。

## Skills

- 输入框下方打开 “Skills”。
- 不选择时由 Agent 自动匹配；显式选择后，本会话只优先加载选定能力。
- 内置“数据分析”适合 SQL、表格、统计和可复核分析。
- 选中项以标签显示，可点击标签移除。
- Skills 按会话持久化，不会自动改动其他会话。

## 文档处理

1. 点击回形针或拖入 PDF、DOCX、XLSX、PPTX。
2. 附件解析后在输入区显示；不需要的附件可移除。
3. 说明是读取、改写、转换还是创建新文档。
4. Agent 创建的文件进入隔离会话产物目录。
5. 展开“Agent 产物”，核对名称和格式，再点击导出。

原文件不会因转换被覆盖。文档读取、创建和转换分别受设置页权限控制。

## 模型与执行字段

| 字段 | 默认值 | 含义 |
|---|---:|---|
| OpenAI 兼容 URL | `http://127.0.0.1/v1` | 模型服务根地址 |
| Model | `deepseek-v4-flash` | 请求中的模型名 |
| 上下文窗口 | `393216`（384K） | 用于裁剪历史的 token 上限 |
| 最大输出 | `98304` | 单轮允许的最大输出 |
| 模型/工具循环 | `64` | 单次请求最大循环，范围 1–256 |
| Python 超时 | `300` 秒 | 项目 Python 单次上限，可到 86400 秒 |
| Temperature | 可配置 | 随机性，越低越稳定 |
| Streaming | 开/关 | 增量或缓冲输出 |

API Key 直接输入时只保留当前应用会话；插件 Provider 可使用宿主安全引用。

## 限制与安全（工具边界）

- 工具总开关关闭后，模型不会看到工具定义；Host 执行时还会复核分类权限。
- 数据库工具只读，不提供 `INSERT`、`UPDATE`、`DELETE` 或 DDL。
- 任意绝对路径文件只读且单文件有限制；项目写入只能发生在绑定项目内。
- Python 仅绑定项目后可用，受超时、输出上限和进程树终止保护。
- RPAZ 校验/构建只对 RPAZ 子集项目开放。
- Knowledge、文档和插件工具分别受设置开关控制。
- 不要把密钥、个人数据或生产写权限交给对话。

## 常见问题与排错

- **请求失败或连接被拒绝**：确认本地服务正在运行，URL 和模型名与服务一致。
- **会话很多导致慢**：正文按需载入；先用项目整理。若列表异常，检查工作区 `agent/session.db` 是否可写。
- **Python 工具不可用**：绑定任意通用项目，并启用总工具开关与 Python；普通会话不能直接运行。
- **Agent 能读但不能写项目**：启用“项目内写入”，并确认目标路径在绑定项目内。
- **选了 Skill 但没有对应工具**：Skill 可能仅提供指令；还需启用扩展工具，且 Skill manifest 必须声明工具。
- **附件读取失败**：检查格式、文件是否损坏/加密和文档读取权限。
- **输出被截断**：调大最大输出需同时确保服务端模型支持；过高值会增加资源和耗时。
- **工具循环达到上限**：检查是否反复调用同一失败工具，先修正输入；不要只盲目提高循环数。
- **删除项目会删除项目文件吗**：Agent 页面目前只提供项目创建/重命名与会话管理，不应把会话删除理解为项目目录删除。
