# 开发工作室

## 页面用途

“开发工作室”是项目级集成开发环境，组合文件树、代码/Notebook 编辑、持久 Python Kernel、项目运行、RPAZ 校验构建，以及绑定当前项目的 AI Agent。

## 适用场景

- 从零创建 Python 自动化或数据分析项目。
- 逐单元调试 DrissionPage 浏览器交互。
- 将 Notebook 原型整理成可运行入口。
- 修改已安装包对应的开发项目。
- 直接把成熟项目保存到 RPAZ 包页面。

## 前置条件

- [运行环境](12_运行环境.md)中的 Python 与 Jupyter Kernel 应可用。
- 需要 RPAZ 构建时，项目根目录必须有合法 `manifest.yaml` 和入口。
- 浏览器自动化需要内置浏览器依赖可用。

## 界面区域

1. **顶部项目与运行工具栏**：选择/创建项目，配置运行参数，运行、导出、保存到 RPAZ 包。
2. **左侧项目与文件树**：项目右键可重命名或删除；文件区可新建、导入、重命名和删除。
3. **中央编辑区**：源码编辑或 Notebook 单元格。
4. **Notebook 输出与变量**：显示 stdout、stderr、结果、变量和耗时。
5. **右侧 AI Agent**：自动绑定当前项目，使用同一套持久会话和工具。
6. **可折叠侧栏**：文件树和 Agent 可独立收起。

## 从项目到可运行包

1. 输入项目名称并创建项目。
2. 需要更名时在左侧项目上右键选择“重命名项目”；内部项目 ID 和目录保持稳定，只更新项目名称与 manifest 顶层 `name`。
3. 在文件树新建入口、模块、资源目录；也可导入已有文件。
4. 用 Notebook 建立最小实验：先运行一小段，再检查输出和变量。
5. 把稳定逻辑移入项目模块，避免把所有代码留在单元格。
6. 添加 `manifest.yaml`，声明 ID、版本、运行时、入口、参数和产物。
7. 在“运行参数”填写 JSON，执行项目并修复错误。
8. 校验通过后：
   - “导出”生成外部 `.rpaz`；
   - “保存到 RPAZ 包”直接安装到当前工作区，适合本地迭代。
9. 到[运行工作台](05_运行工作台.md)用正式参数预检和运行。

## Notebook 操作

- 代码单元格左侧运行按钮只执行该单元格；执行计数显示 Kernel 顺序。
- Markdown 单元格用于记录假设、步骤和结论，不会执行。
- Kernel 持久保存变量，因此结果依赖执行顺序时，应从头重跑确认可复现。
- HTML 输出在受限 iframe 中渲染，不应依赖完整网页权限。

## 字段与状态解释

- **项目**：普通工作目录；只有符合规范才被识别为 RPAZ 项目。
- **运行参数 JSON**：项目入口本次接收的参数，不等于任务配置。
- **stdout/stderr**：普通输出与错误输出；异常还应查看 traceback。
- **变量预览**：用于调试，不保证显示完整大对象。
- **busy/正在运行**：当前操作未结束，应等待再切项目或删除文件。

## 使用右侧 AI Agent

1. 选择项目后，Agent 自动绑定该项目。
2. 新建项目会话，说明目标和允许修改范围。
3. Agent 可读取/修改项目文件并运行项目内 Python；RPAZ 项目额外支持校验和构建。
4. 展开工具事件复核改动和运行输出。
5. 最终仍在编辑区检查 diff，并自己运行关键单元或入口。

完整会话管理、Skills 和文档附件见 [AI Agent](09_AI_Agent.md)。

## 限制与安全

- 删除项目会移除全部项目文件；先保存或导出重要版本。
- Kernel 状态不会进入 RPAZ 包，入口必须能在干净进程中运行。
- 浏览器登录态、Cookie、截图和下载文件可能敏感，不要写入知识文档或提交包。
- Agent 的写入和 Python 分别受[扩展工具](16_扩展工具.md)权限与设置页超时控制。
- “保存到 RPAZ 包”不是发布审批；仍需在运行工作台与运行记录验收。

## 常见问题与排错

- **运行结果依赖前面单元格**：重启/清空 Kernel 后按顺序从头执行，补齐缺失初始化。
- **找不到模块**：确认文件位于项目内，并使用内置 Python；不要依赖系统 Python 的临时包。
- **浏览器脚本卡住**：为元素等待设置合理超时，先缩小到一个可重复页面步骤。
- **导出失败**：检查 manifest 入口、参数类型、相对路径和未声明资源。
- **隐藏大标题后工具栏不见**：运行、导出和保存操作属于工作区工具栏，应仍显示；若布局异常，切换设置后重开页面并记录窗口尺寸。
- **Agent 无法运行 Python**：确认会话绑定了项目，并在设置启用 Agent 工具与 Python。
