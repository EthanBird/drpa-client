# 知识库

## 页面用途

“知识库”将 PDF、Office、网页、文本等来源解析成片段并建立本地向量+关键词混合索引，供 AI Agent 和流程节点进行带引用的语义检索。

## 适用场景

- 导入产品、售后、制度、合同模板或项目资料。
- 对一个或多个资料库做自然语言联合查询。
- 在交给 Agent 前检查召回片段、相关度和引用。
- 为流程设计中的 Knowledge Retrieval 节点准备数据。

## 前置条件

- 当前工作区可写，导入文件可读。
- URL 必须是可公开访问的静态网页；登录页面应先导出。
- Agent 使用时需在[设置](14_设置.md)启用“向量知识库查询”。
- 新来源必须完成索引后才适合查询。

## 界面区域

1. **顶部说明与新建按钮**：明确知识库与知识文档区别。
2. **左侧知识库列表**：选择、刷新、删除，并勾选联合查询范围。
3. **中央来源区**：导入文件/目录、粘贴文本、URL，查看索引统计和来源状态。
4. **右侧查询测试**：输入问题、返回条数、结果分数与引用详情。
5. **可折叠侧栏**：知识库列表与查询区可分别收起。

## 创建与导入流程

1. 点击“新建知识库”，填写名称和用途描述。
2. 选择新库后添加来源：
   - “导入文件”选择单个或多个文件；
   - “导入目录”递归扫描；
   - “粘贴文本”填写标题与正文；
   - “添加 URL”抓取公开网页；
   - 也可把文件或目录拖入中央来源区。
3. 观察来源状态与进度。
4. 状态“已就绪”后检查片段数；失败则展开错误并重新处理源文件。

支持 PDF、Word、Excel、PowerPoint、Markdown、纯文本、CSV、HTML 和 JSON 等常见格式。

## 查询验证流程

1. 在左侧勾选一个或多个知识库；未勾选时通常使用当前库。
2. 右侧输入具体问题，不要只输入宽泛关键词。
3. 选择返回 3、6、10、15 或 20 条。
4. 点击“运行查询”。
5. 先看来源和综合分，再展开“引用详情”检查：
   - 知识库与来源；
   - 片段 ID；
   - 综合/向量/关键词相关度；
   - 引用标识和完整片段。
6. 召回准确后再让 Agent 或流程使用。

## 状态与字段解释

- **pending/待处理**：已登记，尚未开始。
- **indexing/处理中**：正在解析、分块或建立索引。
- **ready/已就绪**：可用于查询。
- **failed/异常**：解析或索引失败，查看错误。
- **chunkCount**：来源切分片段数量；多不等于质量高。
- **score**：混合相关度。
- **vectorScore**：语义相似。
- **keywordScore**：词项匹配。
- **citation**：回答中应保留的来源标识。

## 与知识文档和其他页面协作

- [知识文档](15_知识文档.md)保存可编辑 Markdown 原文，不自动向量化。
- [AI Agent](09_AI_Agent.md)可列库并检索召回片段。
- [流程设计](08_流程设计.md)可使用知识检索节点。
- Excel 需要结构化 SQL 时优先用[数据工作台](04_数据工作台.md)，需要语义检索时才导入知识库。

## 限制与安全

- 索引属于当前工作区，不跨区共享。
- 删除知识库会移除全部来源和索引；删除单个来源也会移除对应片段。
- 导入前检查隐私、版权和留存要求；启用 Agent 查询后召回内容会进入模型上下文。
- URL 抓取不携带浏览器登录态，动态页面可能只有空壳。
- 向量检索不是事实保证；回答必须保留引用并人工核验。
- 大文件和大目录需要时间与磁盘，先小批量验证。

## 常见问题与排错

- **来源一直处理中**：刷新来源列表，检查运行环境资源和文件是否被占用。
- **PDF/Office 解析失败**：确认文件未加密、未损坏，格式与扩展名一致。
- **URL 内容为空**：页面可能依赖 JavaScript 或登录；导出为 PDF/HTML 后导入。
- **查询无结果**：确认至少一个库被选中、来源 ready，并换成包含业务实体的问法。
- **结果不相关**：缩小资料范围、改善源文档标题/段落，或提高返回条数后重排。
- **Agent 不查询知识库**：检查设置权限与会话工具事件；明确要求“检索知识库并给出引用”。
- **删除后仍看到旧结果**：刷新知识库和查询，确认选择范围不包含其他同内容库。
