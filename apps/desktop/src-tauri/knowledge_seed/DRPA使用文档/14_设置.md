# 设置

## 页面用途

“设置”统一管理界面外观、Windows 更新、当前工作区数据迁移、AI Agent 工具权限与模型参数、AGENTS.md/MEMORY.md 和 Skills。

## 适用场景

- 调整主题、字号、密度和页面标题。
- 打开数据目录，导出或导入工作区。
- 配置本地 OpenAI 兼容模型。
- 控制 Agent 可见和可执行的工具类别。
- 调整 64 轮循环、384K 上下文、最大输出与 Python 超时。
- 维护长期指令、记忆和自定义 Skills。

## 前置条件

- 导出/导入和系统文件选择器仅在桌面宿主可用。
- 模型配置前应启动兼容服务并知道模型名。
- Windows 轻量更新只在支持的平台显示。

## 界面区域

1. **语言**：当前完整支持简体中文。
2. **外观**：主题、字号、界面密度、隐藏页面大标题。
3. **Windows 轻量热更新**：选择本地更新包并显示进度。
4. **工作区数据**：数据目录、打开目录、导出和导入。
5. **AI Agent 工具权限**：总开关及分类开关。
6. **AI Agent 配置**：URL、模型、Key、流式与生成参数。
7. **Agent 指令与记忆**：`AGENTS.md`、`MEMORY.md`。
8. **Skills 工作区**：创建、编辑和验证 Skill。

## 外观设置

- **主题**：亮色/暗色即时生效。
- **字号等级**：只缩放文字。
- **界面密度**：紧凑会缩小页签、工具栏与控件。
- **隐藏页面大标题**：隐藏各页顶部标题区，正文应继续占满可用高度。
- 主导航的收窄按钮位于导航本身；收窄后保留图标可点击，不是完全隐藏。

## 导出用户数据

1. 在“当前数据目录”确认工作区。
2. 点击“导出用户数据”。
3. 系统弹出保存窗口；选择目标和文件名。
4. 等待按钮恢复并查看成功/错误提示。
5. 会话数据库使用一致性快照写入迁移包。
6. 将导出包按敏感业务文件保管。

若取消保存窗口，不会生成文件。导出只包含用户数据，不包含 WebView2 或应用安装文件。

## 导入用户数据

1. 点击“导入用户数据”并选择迁移包。
2. Host 验证格式和路径。
3. 导入会创建新的隔离工作区，不覆盖当前工作区。
4. 完成后按提示切换到新工作区，检查项目、会话、知识和包。

不要把“导入”当成当前工作区覆盖恢复；需要合并时应在两个工作区间手工迁移选定内容。

## Agent 工具权限

- **总开关**：关闭后模型只对话，不发送工具定义。
- **只读数据库**：列连接、读结构、只读查询；禁止 DML/DDL。
- **创建连接配置**：可创建 PostgreSQL、MySQL、SQLite、Excel 元数据，不保存密码。
- **任意文件只读**：读取绝对路径文本，单文件最大 2 MiB。
- **向量知识库查询**：列库和检索；知识文档仍按原文工具处理。
- **文档读取/创建/转换**：分别控制附件和隔离产物。
- **项目内写入**：只写当前绑定通用项目；RPAZ 额外校验构建。
- **Python**：只在绑定项目运行，超时使用本页配置。
- **知识与记忆写入**：允许更新 Skill、MEMORY.md 和知识文档。
- **Skills 与插件工具**：加载工作区 Skill 及启用插件工具。

Host 会在执行时再次校验，前端开关不是唯一安全边界。

## Agent 模型字段

| 字段 | 默认/范围 | 说明 |
|---|---|---|
| URL | `http://127.0.0.1/v1` | OpenAI 兼容根地址 |
| Model | `deepseek-v4-flash` | 服务端实际模型名 |
| API Key | 可选 | 只保留当前应用会话 |
| 流式输出 | 开关 | 实时增量 Markdown |
| 上下文窗口 | 默认 393216 | 较早历史裁剪依据 |
| 最大输出 | 默认 98304，最大 131072 | 单轮输出上限 |
| 最大模型/工具循环 | 默认 64，范围 1–256 | 单次请求内部循环 |
| Python 超时 | 默认 300 秒，范围 1–86400 | 单次项目 Python |
| Temperature | 0–2 | 输出随机性 |

提高这些上限会增加内存、耗时和服务端压力，不代表结果一定更好。

## AGENTS.md、MEMORY.md 与 Skills

- `AGENTS.md`：始终生效的工作规则、代码规范和安全约定。
- `MEMORY.md`：短小稳定的跨会话事实；不要保存密钥或临时状态。
- Skill：围绕特定任务的说明与可选工具声明；保存前应验证名称、描述和权限。
- 对话页面可按会话选择 Skills，不会改变其他会话。

## 与其他页面协作

- 配置直接影响[AI Agent](09_AI_Agent.md)和开发工作室右侧 Agent。
- 导出/导入覆盖当前工作区中的项目、包、会话、[知识文档](15_知识文档.md)、[知识库](10_知识库.md)等用户数据。
- Python 超时影响 Agent 项目执行；运行环境重建仍在[运行环境](12_运行环境.md)。

## 限制与安全

- 导出包可能包含源码、会话和业务资料，不能公开分享。
- 导入不覆盖当前工作区，避免误覆盖但也不会自动合并。
- API Key 不持久化；不要写进 AGENTS.md/MEMORY.md。
- 开启任意文件读取会扩大 Agent 可读范围，按实际需要启用。
- 项目写入、Python、文档创建和插件工具具有更高影响，按最小权限使用。
- 更新期间不要强制关闭应用；重要工作区先导出。

## 常见问题与排错

- **导出按钮无反应**：确认运行桌面版；应出现保存窗口。若取消窗口无文件是正常，错误会显示在工作区提示。
- **导出成功但找不到文件**：查看成功提示中的路径，或按保存窗口选定目录查找。
- **导入后当前内容没变**：导入创建新工作区；从顶部工作区菜单切换。
- **模型连接失败**：确认服务启动、URL 以正确 `/v1` 结束、模型名存在，Key 要求匹配。
- **设置了 64 轮仍提前停止**：模型可主动结束，64 是上限不是固定次数。
- **Python 300 秒不够**：逐步调高并检查算法；最长 24 小时，但长任务更应做断点和进度。
- **隐藏大标题后下半屏灰色**：正文布局应填满；切换开关验证并记录具体页面/窗口尺寸，问题不应靠关闭功能规避。
- **关闭工具后 Agent 仍提到工具**：旧消息只是历史文本；新请求不会收到被禁用工具定义。
