# 运行工作台

## 页面用途

“运行工作台”把已安装 RPAZ 包转为一次可控执行：选择包和任务配置、填写 manifest 参数、预检、保存并运行，同时在右侧观察实时日志。

## 适用场景

- 第一次验证新安装或刚保存的 RPAZ 包。
- 为同一包建立开发、测试、生产等不同任务配置。
- 选择文件/目录输入并手工运行。
- 在创建自动化计划前确认参数和产物正确。

## 前置条件

- 当前工作区至少安装一个 RPAZ 包。
- 包的 `manifest.yaml` 参数和入口通过校验。
- 文件/目录参数目标存在，远程服务和凭据已准备。
- 内置运行环境可用。

## 界面区域

1. **左侧 RPAZ 包列表**：搜索并切换包。
2. **任务配置列表**：新建、选择、重命名和删除参数配置。
3. **中央参数表单**：根据 manifest 自动生成字段。
4. **信任/预检提示**：说明包校验和必填项状态。
5. **底部运行栏**：重置、保存、预检和运行。
6. **右侧日志检查器**：按级别查看并搜索实时事件，可跟随最新。

侧栏均可收起。收起只改变布局，不会停止当前任务。

## 标准运行流程

1. 在左侧选择 RPAZ 包。
2. 选择已有任务配置；若用途不同，点击任务配置旁 `+` 新建。
3. 按字段填写参数：
   - 文本、数字和布尔值直接输入；
   - 文件/目录使用“选择”按钮；
   - secret 使用密码输入，避免旁观泄露。
4. 点击“预检并保存”，修复必填和类型错误。
5. 再点击“运行任务”。
6. 观察右侧日志；任务结束后进入[运行记录](06_运行记录.md)检查完整持久化事件和产物。

## 字段与状态解释

- **任务配置/Profile**：一组可复用参数，独立于包本身。
- **required/必填**：为空时预检和运行均应阻止。
- **string/number/boolean**：基础类型；不要用字符串代替数字。
- **file/directory**：宿主选取的本机路径。
- **secret**：敏感输入；不应出现在普通日志。
- **等待运行**：尚未提交。
- **正在运行**：已创建运行实例，按钮会禁用避免重复提交。
- **日志级别**：DEBUG 诊断、INFO 正常过程、WARN 风险、ERROR 失败。

## 与其他页面协作

- 从[RPAZ 包](02_RPAZ包.md)选定包。
- 在[开发工作室](03_开发工作室.md)修复源码或 manifest。
- 到[运行记录](06_运行记录.md)查看最终状态、参数和产物。
- 验证通过后在[自动化计划](07_自动化计划.md)复用包和任务配置。

## 限制与安全

- 普通项目不能直接进入运行工作台，需规范化并保存为 RPAZ。
- 保存配置不会执行任务；预检也不证明外部服务可达。
- secret 不应复制到普通文本参数、JSON 日志或截图。
- 删除任务配置会删除本机保存参数，但不会删除历史运行。
- 同一包升级后参数定义可能变化，应重新预检旧配置。

## 常见问题与排错

- **页面提示没有可运行包**：到 RPAZ 包安装，或从开发工作室保存一个项目。
- **文件参数无效**：使用选择按钮重新选取；不要粘贴相对路径或已移动文件。
- **预检通过但运行失败**：预检只检查静态参数；到运行记录查看外部网络、代码或权限错误。
- **日志一直停在启动**：检查运行环境资源和 Python 状态，等待超时后查看持久化错误。
- **任务配置突然缺字段**：包版本改变了 manifest；新建配置并按新结构填写。
- **误点两次运行**：提交期间按钮会禁用；以运行记录中的唯一 run ID 为准。
