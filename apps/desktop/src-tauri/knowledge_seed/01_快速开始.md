# 从零创建并运行第一个 RPAZ

本章以“输入一句话并生成文本文件”为例，走完创建项目、声明参数、编写入口、直接运行、检查产物和导出安装包的完整流程。

## 1. 创建项目

1. 打开左侧“开发工作室”。
2. 在项目名称中输入 `文本输出示例`。
3. 点击“新建项目”。
4. 工作室会自动生成安全的内部项目 ID 和 package ID。

新项目默认包含：

```text
manifest.yaml
main.py
notebook.ipynb
```

项目显示名称可以是中文；`manifest.id` 则必须符合小写域名式 ID 规则。让工作室生成 ID 可以避免手工命名错误。

## 2. 编写 manifest

将 `manifest.yaml` 替换为：

```yaml
schema: 2
id: local.example-text-output
name: 文本输出示例
version: 0.1.0

entrypoint:
  runtime: python
  module: main.py
  callable: main

runtime:
  python: "3.11.*"

capabilities:
  network:
    allow: []
  filesystem:
    read: []
    write:
      - "$outputs"

parameters:
  - id: message
    type: string
    required: false
    default: "你好，DRPA"
  - id: repeat
    type: number
    required: false
    default: 1
  - id: uppercase
    type: boolean
    required: false
    default: false
```

此清单声明了三个显式默认参数。安装 RPAZ 包后，运行工作台可以直接创建完整任务配置，用户无需先猜测参数结构。

## 3. 编写入口

将 `main.py` 替换为：

```python
from __future__ import annotations


def main(ctx):
    message = str(ctx.params.get("message") or "你好，DRPA")
    repeat = int(ctx.params.get("repeat") or 1)
    uppercase = bool(ctx.params.get("uppercase", False))

    repeat = max(1, min(repeat, 100))
    if uppercase:
        message = message.upper()

    ctx.log.info("文本任务开始 · repeat=%s · uppercase=%s", repeat, uppercase)
    lines = []
    for index in range(1, repeat + 1):
        lines.append(f"{index}. {message}")
        ctx.progress(index / repeat * 90, f"已生成 {index}/{repeat} 行")

    output = ctx.output_file("result.txt", "文本输出结果")
    output.write_text("\n".join(lines) + "\n", encoding="utf-8")
    ctx.log.info("输出完成 · file=%s · lines=%s", output.name, len(lines))
    ctx.progress(100, "文本任务完成")
```

注意以下细节：

- `ctx.params.get()` 提供 Python 侧回退，和 manifest 默认保持一致。
- `repeat` 被限制在 `1..100`，避免错误参数生成超大输出。
- 循环只报告到 `90`，最后写文件成功后再报告 `100`。
- `ctx.output_file()` 既生成安全路径，也向 Host 登记产物。
- `write_text(..., encoding="utf-8")` 明确编码。

## 4. 直接运行工作副本

在工作室的运行参数区域输入：

```json
{
  "message": "RPAZ 直接运行成功",
  "repeat": 3,
  "uppercase": false
}
```

点击“直接运行”。直接运行会读取当前项目的 `manifest.yaml`，校验入口，然后把当前项目目录作为 `ctx.package_dir` 执行，不需要先导出、安装。

预期日志阶段：

```text
任务已创建
文本任务开始 · repeat=3 · uppercase=false
输出完成 · file=result.txt · lines=3
运行成功
```

预期产物 `result.txt`：

```text
1. RPAZ 直接运行成功
2. RPAZ 直接运行成功
3. RPAZ 直接运行成功
```

## 5. 导出 RPAZ

点击“导出 RPAZ”。工作室会：

1. 读取并校验 `manifest.yaml`。
2. 确认入口文件存在。
3. 收集项目文件，统一使用 `/` 作为归档路径分隔符。
4. 在工作区 `build/` 生成 `{id}-{version}.rpaz`。

不要在项目根目录加入运行输出、虚拟环境、浏览器缓存或大体积临时文件；导出会收集项目目录中的普通文件。

## 6. 安装后运行

1. 打开“RPAZ 包”。
2. 导入刚生成的 `.rpaz`，也可以直接拖入应用。
3. 选择“文本输出示例”。
4. 前往“运行工作台”。
5. 根据 manifest 默认值创建任务配置。
6. 修改当前值并运行。
7. 在运行记录和工作区日志中检查结果。

## 7. 常见第一次失败

### `manifest could not be decoded`

检查 YAML 缩进、冒号后空格、字符串引号。不要使用 Tab 缩进。

### `invalid package id`

ID 需要包含至少一个点，每段只允许小写字母、数字和连字符，不能以连字符开头或结尾。例如 `com.example.text-task`。

### `package entrypoint must define callable main(ctx)`

检查 `entrypoint.callable` 是否与 Python 函数名一致，函数是否在模块顶层定义。

### 参数类型不符合预期

运行协议传递 JSON 值。number 可能进入 Python 为整数或浮点数；使用 `int()` / `float()` 做显式转换。boolean 不要使用 `bool("false")` 解析字符串，因为非空字符串会得到 `True`。

### 输出文件没有出现在产物中

不要只写 `ctx.output_dir / "result.txt"`。使用 `ctx.output_file("result.txt", "显示名称")` 获取路径后再写入，Host 才会收到产物事件。
