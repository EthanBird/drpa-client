# 知识库

## 入口与用途

从左侧主导航进入“知识库”。知识库把多种数据源解析、分块并建立本地向量与关键词混合索引，供 AI Agent 进行带引用的检索。

## 创建和导入

1. 点击“新建知识库”，填写名称和用途描述。
2. 选择知识库后导入文件、递归导入目录、粘贴文本或添加公开 URL。
3. 也可以直接把文件或目录拖入中间的数据来源区域。
4. 等待来源状态变为“已就绪”，再进行查询。

支持 PDF、Word、Excel、PowerPoint、Markdown、纯文本、CSV、HTML 和 JSON 等来源。URL 只抓取可公开访问的静态网页；登录态页面应先导出为文件。

## 查询测试

- 在左侧勾选一个或多个知识库进行联合检索。
- 右侧输入问题并选择返回条数。
- 结果展示综合、向量和关键词相关度，以及来源、片段 ID 和引用标识。
- 使用“引用详情”复核完整召回片段，再决定是否交给 Agent 使用。

## 与知识文档的区别

- 知识库：多源、分块、向量化，适合语义检索。
- [知识文档](../15_知识文档/使用说明.md)：可编辑 Markdown 原文，不自动向量化，适合规范、手册和精确引用。

## 安全与限制

- 知识库与索引只属于当前工作区。
- 删除知识库或来源会移除对应索引，操作前确认不再需要。
- 导入前检查敏感信息；启用 Agent 查询权限后，模型可获得召回片段。
- 索引尚未完成或来源失败时，查询结果可能不完整。
