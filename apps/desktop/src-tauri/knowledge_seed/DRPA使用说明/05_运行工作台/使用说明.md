# 运行工作台

## 入口与用途

从左侧主导航进入“运行工作台”。这里负责选择已安装 RPAZ 包、维护任务配置、填写参数、预检并正式运行。

## 标准流程

1. 在左侧选择 RPAZ 包。
2. 选择已有任务配置，或点击任务配置旁的 `+` 新建配置。
3. 根据 `manifest.yaml` 填写字符串、数字、布尔、文件、目录或敏感参数。
4. 点击“预检并保存”检查必填项并保存当前配置。
5. 点击“运行任务”，右侧日志检查启动和执行过程。

任务配置可以重命名或删除。包侧栏与日志侧栏均可收起，把空间留给参数表单。

## 安全与限制

- 只有已安装的 RPAZ 包才能在此运行；普通项目需先在[开发工作室](../03_开发工作室/使用说明.md)规范化并保存为 RPAZ 包。
- 文件和目录参数应使用选择按钮，不要手工输入不确定的路径。
- 密码类输入不会以明文显示；不要把敏感值写进普通文本参数。
- 预检不等于正式运行，运行结果应到[运行记录](../06_运行记录/使用说明.md)复核。
