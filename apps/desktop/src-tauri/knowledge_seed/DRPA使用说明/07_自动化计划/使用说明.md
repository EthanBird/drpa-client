# 自动化计划

## 入口与用途

从左侧主导航进入“自动化计划”。它负责按本机时间表运行已安装 RPAZ 包，并可把结果投递到一个或多个目标。

## 创建计划

1. 点击“新建计划”，填写名称、说明、RPAZ 包、运行配置和参数 JSON。
2. 选择时间类型：每天、每周、固定间隔或五段式 Cron。
3. 配置并发策略：已有实例时跳过，或允许并行。
4. 设置单次超时、重试次数、重试间隔和退避倍数。
5. 按需添加应用内通知、邮件、Webhook 或频道等投递目标。
6. 创建后可启用、暂停、编辑或“立即运行”验证。

页面也提供新闻摘要、报告生成、多频道广播和 RPAZ 定时运行等模板入口。

## 安全与限制

- 调度使用本机时区，时间精确到分钟；修改系统时区后应复核下次运行时间。
- Cron 必须是五段表达式。
- 投递配置可能包含 URL 或频道标识，敏感凭据不应直接写入可见 JSON。
- 正在运行的计划不能删除；删除计划后，既有运行历史仍保留用于审计。
- 计划只运行已安装 RPAZ 包，不直接运行普通 Agent 项目。
