# 知识文档

## 入口与用途

点击左侧主导航底部的“知识文档”。这里是当前工作区内可编辑的离线 Markdown 文档树，适合保存规范、操作手册、业务约定和故障经验。

## 文件树操作

- 在文件树空白处右键，可创建最外层文档或最外层目录。
- 在目录上右键，可新建子文档、子目录、重命名或删除。
- 在文档上右键，可重命名、导出或删除。
- 支持选择或拖入多个 UTF-8 编码的 `.md`、`.markdown` 文件。
- 搜索框按文档名称过滤；刷新按钮重新读取当前工作区目录。

## 阅读和编辑

- 右上角可在阅读、编辑和分栏模式间切换。
- 修改后点击保存，或使用 `Ctrl+S`。
- 文档中的相对 Markdown 链接会在知识文档内部打开；HTTP/HTTPS 链接交给外部浏览器。
- 状态栏显示保存提示、编码、格式和字符数。

## 与知识库的区别

知识文档保留完整 Markdown 原文，便于人工编辑和精确链接，但不会自动向量化。需要让 AI Agent 对大量异构资料做语义检索时，应导入[知识库](../10_知识库/使用说明.md)。

## 安全与限制

- 只接受 Markdown 文件，单篇文档有大小限制，并拒绝路径穿越和符号链接。
- 删除目录会删除其中全部文档，确认前请检查范围。
- 默认说明只在目标文件不存在时写入，更新种子不会覆盖用户已经修改的同名文档。
- 知识文档属于当前工作区；切换工作区后看到的是另一套文档树。
