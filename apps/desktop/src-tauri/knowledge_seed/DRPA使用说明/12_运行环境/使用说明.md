# 运行环境

## 入口与用途

从左侧主导航进入“运行环境”。此页展示 DRPA 内置 Python、Jupyter Kernel、浏览器自动化依赖及本机资源状态。

## 页面内容

- Python + RPA：显示封装 Python 版本、环境状态和路径。
- Jupyter Kernel：显示交互开发 Kernel 的可用状态。
- 浏览器自动化：显示 DrissionPage 等依赖状态。
- 本机资源监控：每 2 秒在普通用户权限下刷新 CPU、物理内存和各本地磁盘用量，不要求管理员权限。

## 环境修复

当内置运行时确实损坏时，可使用“强制重建运行环境”。该操作会停止 Studio Kernel，删除并离线重建应用数据目录中的 `runtime-environment`，通常需要数分钟；RPAZ 包、项目和运行产物会保留。

## 安全与限制

- 资源监控是采样值，短时波动属于正常现象。
- CPU 首次采样需要两个计数器时间点，可能短暂显示“正在采样”。
- 强制重建是高成本操作，不应作为普通刷新按钮使用；先记录错误并关闭正在运行的 Notebook。
- 重建运行环境不会修复项目源码、Provider 配置或远程数据库连接。
