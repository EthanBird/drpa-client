# AI Agent

## 入口与用途

从左侧主导航进入“AI Agent”。它面向普通问答、项目开发、数据分析、知识查询和办公文档处理。会话正文保存在当前工作区的 `agent/session.db`，会话数量不设固定上限并按需载入。

## 会话与项目

- 左上“新建普通会话”创建不绑定项目的对话。
- “项目”区域按文件夹组织会话；在空白处或项目上右键可新建项目、在项目中新建会话或重命名通用项目。
- 普通会话可通过右侧“工作上下文”移动到项目。
- “最近会话”按更新时间列出会话；会话可重命名、清空或删除。
- 通用项目允许项目内文件和 Python 工具；RPAZ 是带校验与构建能力的规范化项目子集。

## 对话、Skills 与文档

- 在输入框发送文字，`Ctrl+Enter` 快速提交；可编辑最后一条用户消息后重新生成。
- 输入框下方的 “Skills” 可显式选择本次会话能力；不选择时由 Agent 自动匹配。内置“数据分析”Skill 适合 SQL、表格与统计任务。
- 可选择或拖入 PDF、Word、Excel、PowerPoint，Agent 能按已启用权限读取、创建或转换文档；产物保存在隔离的会话目录并可导出。
- 工具调用记录会显示名称、状态、摘要和输出，便于复核。

## 默认模型参数

- OpenAI 兼容 URL：`http://127.0.0.1/v1`
- 模型：`deepseek-v4-flash`
- 上下文窗口：384K，即 `393216` tokens
- 最大输出：`98304` tokens
- 单次模型/工具循环：默认 `64`，可配置 `1–256`
- Python 超时：默认 `300` 秒，可配置到 `86400` 秒

这些值可以在右侧配置栏或[设置](../14_设置/使用说明.md)中修改。

## 安全边界

- 工具总开关和分类权限由 Host 再次校验；关闭后模型看不到相应工具。
- 数据库工具始终只读，不提供数据写入或 DDL 工具。
- 任意文件读取只读且有大小限制；写入严格限制在当前绑定项目或会话产物目录。
- Python 必须绑定项目后运行，并受超时、输出大小和子进程终止策略约束。
- API Key 默认只保留在当前应用会话内，不写入磁盘。
