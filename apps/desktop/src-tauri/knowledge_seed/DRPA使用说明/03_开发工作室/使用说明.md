# 开发工作室

## 入口与用途

从左侧主导航进入“开发工作室”。它把项目文件编辑、Notebook 单元格、持久 Python Kernel、RPAZ 校验与构建集中在同一页，右侧还嵌入了与 AI Agent 页面共用会话能力的项目助手。

## 项目与文件

- 新建项目时只需填写名称；项目文件保存在当前工作区。
- 左侧文件树支持新建文件、文件夹、导入、重命名和删除。
- 可以选择已安装 RPAZ 包作为开发来源。
- 工具栏支持运行、导出 `.rpaz`，以及直接“保存到 RPAZ 包”供运行工作台使用。

## Notebook 与运行

- 代码和 Markdown 单元格可以新增、编辑、删除和单独运行。
- Python Kernel 在项目开发期间保持状态，适合逐步检查变量、数据和浏览器交互。
- 项目运行参数使用 JSON；正式运行前应保证参数结构与 `manifest.yaml` 一致。

## 右侧 AI Agent

- Agent 自动绑定当前开发项目，可读取和修改项目文件并执行项目内 Python。
- 普通项目可使用文件与 Python 工具；含 RPAZ 规范的项目还可校验和构建。
- 会话与独立 [AI Agent](../09_AI_Agent/使用说明.md) 页面共享并持久化。

## 安全与限制

- 删除项目会连同项目目录一起删除，确认前请先导出或保存需要保留的内容。
- Python 运行受[设置](../14_设置/使用说明.md)中的工具权限和超时控制。
- 浏览器自动化应在项目中编写和调试，避免把账号、令牌或个人数据写入 Notebook 输出。
