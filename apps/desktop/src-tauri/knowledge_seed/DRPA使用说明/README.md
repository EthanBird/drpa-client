## 先理解三个边界

- **工作区隔离**：项目、RPAZ 包、运行记录、会话、知识文档、向量知识库和产物都属于当前工作区。切换工作区后，桌面端会重新加载对应数据。
- **通用项目与 RPAZ**：通用项目是普通工作目录；带 `manifest.yaml` 且遵循 RPAZ 规范的项目是可校验、构建、安装和运行的规范化子集。
- **知识文档与知识库**：知识文档是可编辑的 Markdown 原文，不自动向量化；知识库用于导入多种来源、分块和向量检索，主要供 AI Agent 查询。

## 通用界面操作

- 左侧主导航可以收窄为图标栏，收窄后仍可通过图标切换页面。
- 多数工作台自己的左右侧栏也可以独立收起和恢复。
- `Ctrl+K` 打开命令面板。
- “设置 → 外观”可以切换亮/暗主题、字号、界面密度，并隐藏页面大标题。

建议第一次使用按以下顺序阅读：[设置](14_设置/使用说明.md) → [运行环境](12_运行环境/使用说明.md) → [开发工作室](03_开发工作室/使用说明.md) → [运行工作台](05_运行工作台/使用说明.md)。
