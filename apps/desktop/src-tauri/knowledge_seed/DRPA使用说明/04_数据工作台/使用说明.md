# 数据工作台

## 入口与用途

从左侧主导航进入“数据工作台”。这里用于管理数据源、浏览结构并执行查询，支持 PostgreSQL、MySQL、SQLite 和 Excel 类文件。

## 创建连接

1. 点击“连接”标题旁的 `+`。
2. 选择 PostgreSQL、MySQL、SQLite 或 Excel。
3. 远程数据库填写主机、端口、数据库和用户名；密码只保留在当前应用会话的内存中。
4. SQLite 可选择 `.db`、`.sqlite`、`.sqlite3`；Excel 支持 `.xls`、`.xlsx`、`.xlsb`、`.ods`。
5. 也可以把 SQLite 或 Excel 文件直接拖入页面创建文件数据源。

## 查询与分析

- 左侧选择连接、表或视图；单击查看字段，双击可生成查询。
- 中央 SQL 编辑器执行查询并以表格显示结果。
- “AI SQL 助手”读取当前结构后生成 SQL，但不会自动执行；请先审阅再运行。
- 文件型数据源可通过“打开目录”定位工作区副本。

## 安全与限制

- AI Agent 的数据库工具只提供列连接、读结构和只读查询，不提供 `INSERT`、`UPDATE`、`DELETE` 或 DDL 工具。
- Excel 工作簿按只读数据源查询，不会回写原工作簿。
- 数据源配置属于当前工作区；导入文件前请确认其中不包含不应复制到工作区的敏感信息。
