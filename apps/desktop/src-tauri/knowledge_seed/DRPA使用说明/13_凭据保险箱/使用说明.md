# 凭据保险箱

## 当前状态

从左侧主导航进入“凭据保险箱”。当前页面仍处于开发中，尚未接入完整的 Host 凭据服务，因此页面不会伪装可用的保存、读取或绑定操作。

## 设计目标

完成后，任务和插件应只持有凭据引用，由宿主在受控边界内注入真实值。真实凭据不应进入：

- RPAZ 包及 `manifest.yaml`
- 项目源码或 Notebook
- 运行参数快照和运行日志
- AI Agent 对话、知识文档或向量知识库
- 流程 DSL 与插件清单

## 现阶段怎么做

- AI Agent 和流程 Provider 的 API Key 输入遵循各自页面说明；Agent 的直接 API Key 默认只保留在当前应用会话。
- 远程数据库密码只保留在本次应用运行的内存中。
- 不要因为保险箱入口存在，就假定敏感值已经被系统持久化保护。
