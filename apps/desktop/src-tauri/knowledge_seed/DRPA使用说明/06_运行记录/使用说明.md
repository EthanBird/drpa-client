# 运行记录

## 入口与用途

从左侧主导航进入“运行记录”。该页用于审计当前工作区中每次 RPAZ 执行，而不是修改任务。

## 核心操作

- 使用搜索框按运行 ID、RPAZ 包或任务配置过滤。
- 选择一条记录后查看状态、开始时间、耗时与进度。
- “概览”显示执行摘要。
- “日志”可按消息、作用域和级别筛选，并复制筛选后的日志。
- “产物”列出登记的输出文件，支持复制完整路径。
- “参数”展示本次实际提交的参数。
- “输出目录”在文件管理器中打开该次运行的产物目录。

## 状态说明

常见状态包括排队中、运行中、成功、失败、已取消和意外中断。若任务异常结束，先在日志中定位最后一个错误事件，再到[运行环境](../12_运行环境/使用说明.md)检查 Python 与宿主状态。

## 安全与限制

- 运行历史属于当前工作区并持久化，用于审计。
- 日志和参数可能包含业务内容，复制或分享前请检查敏感信息。
- 删除自动化计划不会删除已经产生的运行历史。
