# 设置

## 入口与用途

点击左侧主导航底部的“设置”。这里统一管理界面、工作区数据、AI Agent 权限与模型参数、指令记忆、Skills 和 Windows 更新。

## 外观

- 切换亮色或暗色主题。
- 调整字号等级和舒适/紧凑界面密度。
- “隐藏页面大标题”只隐藏各页顶部标题区，不应裁剪页面正文。
- 左侧主导航可收窄为保留图标的导航栏；各工作台侧栏独立控制。

## 工作区数据

- 查看并打开当前数据目录。
- “导出用户数据”弹出保存窗口，生成工作区迁移包，并显示成功或错误提示。
- “导入用户数据”选择迁移包后创建新的隔离工作区，不覆盖当前工作区。
- 会话数据库会以一致性快照进入导出包。

## AI Agent

- 配置 OpenAI 兼容 URL、模型、流式输出、上下文、最大输出、循环数、Python 超时和 Temperature。
- 默认 URL 为 `http://127.0.0.1/v1`，模型为 `deepseek-v4-flash`，上下文为 384K，最大输出为 98304，循环数为 64，Python 超时为 300 秒。
- API Key 只保留到当前应用会话，不写入磁盘。
- 工具总开关关闭后，模型不会收到工具定义；分类权限由 Host 执行时再次校验。
- 数据库工具强制只读；任意文件只读、项目写入、Python、文档处理、知识查询和扩展工具均可独立启停。

## Agent 指令、记忆与 Skills

- `AGENTS.md` 保存始终生效的工作约定。
- `MEMORY.md` 只保存短小、稳定、适合跨会话复用的事实。
- Skills 编辑区用于创建和维护工作区能力；对话中还可以按会话选择 Skills。

## 安全与限制

- 导出包可能包含项目、会话和业务文档，应按敏感数据文件保管。
- 导入会新建工作区，不会合并或覆盖当前数据。
- 增大上下文、输出、循环或 Python 超时会增加耗时和资源使用。
- Windows 文件级更新不会覆盖 WebView2 和用户数据；更新前仍建议先导出重要工作区。
