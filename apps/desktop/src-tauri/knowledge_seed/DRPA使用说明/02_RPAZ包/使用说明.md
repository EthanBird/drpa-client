# RPAZ 包

## 入口与用途

从左侧主导航进入“RPAZ 包”。此页管理当前工作区内已安装的 `.rpaz` 自动化包。

## 核心操作

1. 点击“安装 RPAZ 包”，选择本地 `.rpaz` 文件。
2. 使用搜索框按名称、ID 或运行环境过滤。
3. 在网格和列表视图之间切换。
4. 选择包后查看描述、版本、运行时、参数与任务配置，并可进入运行工作台。

开发工作室中的 RPAZ 项目可以直接“保存到 RPAZ 包”，无需先导出再安装；外部包仍可通过安装按钮或拖入桌面窗口完成安装。

## 安全与限制

- 安装时会校验压缩路径、包体规模和 `manifest.yaml`，避免越界文件进入工作区。
- RPAZ 包是规范化项目的发布形态；普通 Agent 项目不会自动出现在这里。
- 包中的敏感信息不应写入源码或清单，应使用参数或凭据引用。
