# 参数、输出与产物设计

可靠的自动化不是“代码能跑一次”，而是同一个包能用不同任务配置重复运行，输入明确、输出稳定、失败可解释。本章集中说明参数建模、文件路径、数据格式和产物登记。

## 1. 参数设计原则

一个参数应该代表用户愿意在运行前决定的事情。实现细节不要全部暴露为参数。

适合作为参数：

- 业务范围：日期、地区、关键词、最大条数。
- 执行模式：是否无头、是否覆盖、是否生成附加报告。
- 外部输入：文件、目录、凭据引用。

不适合作为参数：

- Runtime 固定路径。
- Chrome 可执行文件位置。
- 内部临时文件名。
- 代码本身可以稳定推导的 CSS selector 顺序。

## 2. 参数类型模板

```yaml
parameters:
  - id: keyword
    type: string
    required: true
  - id: max_results
    type: number
    required: false
    default: 20
  - id: headless
    type: boolean
    required: false
    default: true
  - id: account_token
    type: secret
    required: true
  - id: source_file
    type: file
    required: false
  - id: source_directory
    type: directory
    required: false
```

Python 中立即规范化：

```python
from pathlib import Path

keyword = str(ctx.params.get("keyword") or "").strip()
if not keyword:
    raise ValueError("keyword 不能为空")

max_results = int(ctx.params.get("max_results") or 20)
max_results = max(1, min(max_results, 500))

headless = bool(ctx.params.get("headless", True))

source_file_raw = str(ctx.params.get("source_file") or "").strip()
source_file = Path(source_file_raw) if source_file_raw else None
if source_file and not source_file.is_file():
    raise ValueError(f"输入文件不存在：{source_file}")
```

## 3. required 与 default

`required: true` 表示任务配置必须提供值；`default` 表示工作台可以用一个确定值初始化。两者可以同时存在，但通常：

- 业务上必须由用户选择的凭据或输入文件：required true，不设默认。
- 有合理通用行为的选项：required false，显式默认。
- 字符串为空和字段缺失不是同一件事，代码需要按业务区分。

例如关键词不能空：

```python
keyword = str(ctx.params.get("keyword") or "").strip()
if not keyword:
    raise ValueError("搜索关键词不能为空")
```

而可选备注允许空字符串：

```python
note = str(ctx.params.get("note", ""))
```

## 4. 数值范围和枚举

manifest 当前声明 number，但不声明 min/max/enum。因此范围验证属于入口代码：

```python
count = int(ctx.params.get("count") or 1)
if not 1 <= count <= 8:
    raise ValueError("count 必须在 1 到 8 之间")
```

“拒绝”与“截断”要按业务选择：

```python
# 用户输入错误应明确失败
if max_pages < 1:
    raise ValueError("max_pages 必须大于 0")

# 外部 API 有硬上限，可在日志说明后截断
if max_pages > 100:
    ctx.log.warning("max_pages=%s 超过接口上限，按 100 执行", max_pages)
    max_pages = 100
```

枚举：

```python
format_name = str(ctx.params.get("format") or "json").lower()
if format_name not in {"json", "csv", "markdown"}:
    raise ValueError(f"不支持的 format：{format_name}")
```

## 5. 凭据参数

secret 值或引用不要进入：

- `ctx.log` 消息。
- 输出 JSON。
- 文件名。
- URL 查询字符串。
- 抛出的完整异常文本。

日志只记录是否配置：

```python
token = str(ctx.params.get("account_token") or "")
if not token:
    raise ValueError("未配置账号凭据")
ctx.log.info("账号凭据已加载")
```

请求失败时不要打印完整 headers。可以打印状态码、主机和业务请求 ID。

## 6. 输入文件与目录

文件参数进入 Python 后是字符串。处理前检查：

```python
source = Path(str(ctx.params.get("source_file") or ""))
if not source.is_file():
    raise ValueError("请选择有效输入文件")
if source.stat().st_size > 50 * 1024 * 1024:
    raise ValueError("输入文件超过 50 MiB")
if source.suffix.lower() not in {".csv", ".xlsx"}:
    raise ValueError("只支持 CSV 或 XLSX")
```

读取文本必须明确编码，必要时处理 BOM：

```python
text = source.read_text(encoding="utf-8-sig")
```

目录遍历要限制数量、深度和文件类型：

```python
files = sorted(path for path in source_dir.rglob("*.csv") if path.is_file())
if len(files) > 1_000:
    raise ValueError("输入目录中的 CSV 超过 1000 个")
```

## 7. 使用 `ctx.output_file()`

每个用户应查看或下载的最终文件都通过此 API 创建：

```python
report = ctx.output_file("reports/summary.md", "执行摘要")
report.write_text(markdown, encoding="utf-8")
```

相对路径可以含子目录：

```python
ctx.output_file("data/raw/items.json", "原始数据")
ctx.output_file("data/normalized/items.csv", "标准化数据")
ctx.output_file("screenshots/login-error.png", "登录失败截图")
```

禁止：

```python
ctx.output_file("C:/Users/name/Desktop/result.txt")
ctx.output_file("../../result.txt")
```

Runtime 会解析并验证路径包含关系。

## 8. 原子写入模板

对关键 JSON/CSV，先写临时文件再替换，避免中途失败留下半文件：

```python
import json
from pathlib import Path


def write_json_atomic(target: Path, data) -> None:
    temporary = target.with_suffix(target.suffix + ".tmp")
    temporary.write_text(
        json.dumps(data, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    temporary.replace(target)
```

调用：

```python
target = ctx.output_file("result.json", "JSON 结果")
write_json_atomic(target, records)
```

注意 `output_file()` 会先登记目标文件，不要把 `.tmp` 登记成产物。

## 9. JSON 输出

```python
payload = {
    "schema": 1,
    "package_id": ctx.package_id,
    "run_id": ctx.run_id,
    "count": len(items),
    "items": items,
}
target.write_text(
    json.dumps(payload, ensure_ascii=False, indent=2),
    encoding="utf-8",
)
```

推荐在输出数据中加入自身 schema 版本，便于下游升级。不要依赖 Python `repr()` 作为交换格式。

## 10. CSV 输出

Windows Excel 兼容可使用 `utf-8-sig` 和 `newline=""`：

```python
import csv

target = ctx.output_file("items.csv", "CSV 结果")
with target.open("w", encoding="utf-8-sig", newline="") as stream:
    writer = csv.DictWriter(stream, fieldnames=["title", "url"])
    writer.writeheader()
    writer.writerows(items)
```

字段顺序显式声明，不要依赖第一条数据恰好包含所有字段。

## 11. Markdown 输出

Markdown 很适合同时供人阅读和供 AI Agent 检索：

```python
lines = ["# 执行结果", "", f"共 {len(items)} 条。", ""]
for index, item in enumerate(items, start=1):
    lines.append(f"{index}. [{item['title']}]({item['url']})")
target = ctx.output_file("result.md", "Markdown 报告")
target.write_text("\n".join(lines) + "\n", encoding="utf-8")
```

外部文本中的 `]`, `)`, 换行等字符可能破坏 Markdown，需要按数据来源做清理或转义。

## 12. 二进制和下载

流式复制比一次性 `response.read()` 更适合大文件：

```python
from shutil import copyfileobj
from urllib.request import urlopen

target = ctx.output_file("download/archive.zip", "下载归档")
with urlopen(url, timeout=60) as response, target.open("wb") as output:
    copyfileobj(response, output, length=1024 * 1024)
```

下载后检查大小；业务有校验值时再验证。超时、HTTP 错误和磁盘错误应抛出，让 Host 把运行标记为失败。

## 13. 产物命名

推荐：

- 文件名稳定且可排序：`2026-07-invoices.csv`。
- 使用 ASCII 字母、数字、点、下划线、连字符，跨工具兼容更好。
- label 使用中文业务名称：`2026 年 7 月发票 CSV`。
- 同次运行多个同类文件时包含序号或业务 ID。

文件名清理：

```python
import re


def safe_filename(value: str, fallback="output") -> str:
    cleaned = re.sub(r"[^a-zA-Z0-9._-]+", "-", value).strip("-.")
    return cleaned or fallback
```

## 14. 输出完成检查

```python
if not target.is_file():
    raise RuntimeError("输出文件未生成")
size = target.stat().st_size
if size == 0:
    ctx.log.warning("输出文件为空 · name=%s", target.name)
ctx.log.info("产物就绪 · name=%s · bytes=%s", target.name, size)
ctx.progress(100, "输出完成")
```
